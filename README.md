# VR Ball Collector

This is a Virtual Reality Unity project where the player collects balls.

## Project Description
The project features a VR environment where balls are spawned or placed, and the player must interact with them or collect them using VR controls.

## Requirements
- Unity 2022.3 or later
- XR Interaction Toolkit
- Compatible VR Headset (e.g., Meta Quest)

## How to Play
1. Open the project in Unity.
2. Load the main scene in the Assets/Scenes folder.
3. Press Play and use your VR controllers to interact with the environment and collect the balls.
